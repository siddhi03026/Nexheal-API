# NexHeal AI Frontend

AI-Powered Autonomous API Healing Platform Frontend

## 🚀 Overview

NexHeal AI is an intelligent API monitoring and self-healing platform that helps detect API failures, analyze root causes using AI, and automate recovery processes.

This repository contains the frontend built with React and Tailwind CSS.

---

# ✨ Features

- Secure Authentication
- Protected Dashboard
- API Monitoring UI
- Real-Time Notifications
- AI Chatbot Interface
- Healing Controls
- Report Downloads
- Alerts & Incident Tracking
- Responsive Modern UI

---

# 🛠 Tech Stack

- Tailwind CSS
- Axios

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/siddhi03026/Nexheal-API.git
```

## Install Dependencies

```bash
npm install
```

## Run Development Server

```bash
npm run dev
```

---

# 🌐 Environment Variables

Create `.env`

VITE_API_BASE_URL=http://localhost:8000
